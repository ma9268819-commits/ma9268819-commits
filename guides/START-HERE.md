# 🧭 ابدأ هنا — GitHub ببساطة

[العودة إلى الصفحة الرئيسية](../README.md)

## أول زيارة: ثلاث خطوات

1. افتح قائمة المشاريع من الصفحة الرئيسية، واختر مشروعًا يخدم احتياجك.
2. اقرأ شرحه هنا أو ابعت رابطه إلى ChatGPT لشرحه بالعربي.
3. لو أعجبك، اضغط **Star** لحفظه؛ وجوده في المفضلة لا يثبّته على جهازك.

## قاموس الأزرار

| الزر | معناه واستخدامه |
| --- | --- |
| Repository | مستودع: ملفات المشروع وتعليماته وتاريخ تعديلاته |
| README | أول ملف تقرأه لفهم المشروع وتشغيله |
| Star | حفظ المشروع في المفضلة |
| Follow | متابعة شخص من بروفايله |
| Watch | اختيار إشعارات المشروع؛ يختلف عن الحفظ |
| Releases | إصدارات منشورة قد تحتوي على تطبيق جاهز |
| Code → Download ZIP | تنزيل ملفات المصدر؛ ليست بالضرورة تطبيقًا جاهزًا |
| Fork | نسخة من المستودع في حسابك؛ استخدامها يخضع للترخيص |
| Issues | بلاغات المشاكل والأسئلة المتعلقة بالمشروع |
| Pull request | اقتراح تعديلات يمكن مراجعتها ودمجها |
| Commit | تعديل محفوظ في تاريخ المشروع |

## كيف تختار؟

- ابدأ بالحاجة: ماذا تريد أن تنجز؟
- راجع الأجهزة المدعومة وطريقة التثبيت.
- ميّز بين تطبيق جاهز وأداة تحتاج إعدادًا تقنيًا.
- راجع التحديثات والترخيص والتكاليف، وليس عدد النجوم وحده.

## استفد من ChatGPT عمليًا

انسخ الطلب المناسب وأضف رابط المشروع:

### فهم مشروع
«اشرح هذا المشروع بالعربي البسيط: فائدته، مثال استخدام حقيقي، الأجهزة المدعومة، التكاليف، وهل يحتاج برمجة. فرّق بين المعلومات المؤكدة وما يحتاج تحققًا. الرابط: …»

### مقارنة مشروعين
«قارن المشروعين لاحتياجي التالي: … وعلى جهازي: … وضح سهولة التشغيل والتكلفة والقيود، ثم اقترح الأنسب مع السبب. الروابط: …»

### تشغيل مشروع
«راجع تعليمات المشروع ثم ساعدني أشغّله خطوة خطوة على جهازي: … لا تفترض أن تنزيل ZIP يعني تثبيت التطبيق. الرابط: …»

### تعديل مشروع
«افهم المشروع الحالي وتعليماته، ثم نفّذ التعديل التالي: … واختبر ما يمكن اختباره واشرح التغييرات. الرابط: …»

## القراءة بالعربي على الموبايل

افتح الصفحة في متصفح يدعم الترجمة، واختر ترجمة الصفحة إلى العربية. توافر الخيار ومكانه يختلفان حسب المتصفح.

## ما الذي يتحدث تلقائيًا؟

- نتائج البحث والترند: تُجلب من GitHub عند فتح الرابط، وقد تخضع لتأخر الفهرسة.
- وصف المشاريع المختارة والدليل: نصوص ثابتة تحتاج مراجعة عند تغير المشروع.
- سجل التجارب: يدوي؛ لا يتزامن مع النجوم أو التثبيت تلقائيًا.
- لا يوجد تقرير يومي مجدول أو برنامج مثبت من خلال هذه الصفحة.
