# رادار — GitHub بالعربي

واجهة مستقلة خفيفة مستوحاة من GitHunt، مع إعادة تنفيذ للواجهة بالعربية للموبايل، دون الاعتماد على حزمة React القديمة. تمت مراجعة مصدر GitHunt عند commit `3cd193c745ef8795df1384fbf32b1600c5affc5d`، خصوصًا بناء استعلام البحث حسب تاريخ الإنشاء والترتيب بالنجوم.

- المصدر: https://github.com/nilbuild/githunt
- الترخيص الأصلي محفوظ في dist/LICENSE-GitHunt.txt.
- مصادر الواجهة في web/، ومسار الترجمة في worker/handler.mjs. يُضمّن البناء الأصول داخل worker/index.js، ثم يُخرج dist/server/index.js وفق ملف الاستضافة.
- بيانات مباشرة من GitHub Search API بلا توكن أو تسجيل دخول.
- تحديث كل خمس دقائق أثناء ظهور الصفحة في المقدمة، وعند طلب المستخدم.
- فلاتر «جديدة» تعتمد على تاريخ الإنشاء، وليست سرعة اكتساب النجوم.
- النسخة الاحتياطية snapshot.json لها وقت جلب واضح؛ لا تُعرض باعتبارها بيانات مباشرة.
- المفضلة وحالة التجربة محفوظة محليًا في المتصفح ولا تتزامن مع نجوم حساب GitHub.
- الشرح العربي للمشاريع الشائعة تحريري؛ الأوصاف الأخرى تُترجم تلقائيًا للعربية عبر MyMemory عند ظهور البطاقة. يرسل الموقع أوصافًا عامة فقط ويحفظ الترجمات في المتصفح لمدة 30 يومًا.
- حد الطلب في الخدمة 500 بايت؛ تقسم النصوص إلى مقاطع لا تتجاوز 450 بايت. للخدمة حدود استخدام؛ لا نعرض رسائل فشلها باعتبارها ترجمة ناجحة.
- تفاصيل المشروع تقرأ بياناته ودليل README والإصدار المستقر الأخير عبر GitHub API داخل الموقع. الدليل متاح أصليًا، ويمكن ترجمة النص المستخلص على دفعات 1200 حرف؛ تستبعد كتل الكود والصور من الترجمة.
- أسماء المشاريع وملفات التنزيل والأوامر البرمجية تبقى أصلية للتعريف الصحيح. لغات البرمجة معروضة بأسماء عربية.
- البحث العربي يتضمن تحويلات محدودة للكلمات وليس محرك ذكاء اصطناعي.
- المقارنة تعرض بيانات فعلية ولا تختلق تقييم جودة أو توافق أجهزة.

## التحقق

node --test tests/*.test.mjs
node --check web/app.js

يتطلب التشغيل من خادم HTTP أو الاستضافة المنشورة (بسبب ES modules).

## حدود التحقق

نجحت اختبارات منطق التطبيق والجلب والترجمة والتفاصيل باستخدام محاكاة الشبكة. اختُبر اتصال حي بخدمة الترجمة وتأكدت ترويسة CORS، وجُلبت بيانات فعلية من GitHub. لا يتوفر فحص بصري في متصفح فعلي في هذه البيئة.

## بطاقة القرار ومسارات المهام

- decisions.mjs يحتفظ بتصنيف تحريري لمجموعة محدودة من المشاريع، مع رابط المصدر وتاريخ المراجعة. لا يستنتج التوافق من النجوم أو لغة الكود.
- عند نقص دعم النظام أو المتطلبات تظهر الملاءمة «غير مؤكدة». الملاءمة المبدئية ليست اختبار تشغيل.
- فلاتر الجهاز والخبرة ونوع الاستخدام تُطبق على النتائج المحمّلة فقط. خيار المطابق فقط يستبعد الحالات غير المصنفة.
- مسارات نقل الملفات والمستندات والتعلم والأتمتة والذكاء المحلي تجلب بيانات قائمة إرشادية محدودة من مستودعاتها مباشرة، وليست محرك توصيات شاملًا.
- تفاصيل المشاريع التعليمية تفتح روابط التعلم بدل محاولة جلب ملفات إصدار.
- خطة التجربة وقائمة التحقق محفوظتان محليًا. المستخدم يحدد إتمام الخطوات؛ الموقع لا ينفذ البرامج أو يتحقق من نجاح التشغيل تلقائيًا.
- نُظّف مستخلص الدليل من كيانات HTML والشارات وروابط Markdown المتداخلة قبل الترجمة، مع إبقاء الأصل كاملًا للرجوع إليه.

## إصلاح خدمة الترجمة

- طلبات الواجهة تذهب إلى /api/translate على أصل الموقع نفسه؛ يملك الخادم عنوان المزود الثابت ولا يقبل عناوين خارجية من الطلب.
- يطبق المسار تحقق Origin وحد نص 450 بايت ولغات محددة، مع تسلسل طلبات المزود وفاصل زمني وتخزين مؤقت للنتائج الناجحة.
- تُميز رسائل حد الاستخدام ورفض المزود والمهلة وانقطاع الشبكة. لا نخفي توقف المزود أو نضمن خدمة مجانية غير محدودة.
- يحفظ العميل كل مقطع ناجح فورًا؛ ترجمة الدليل تستأنف من آخر جزء مكتمل بعد الفشل.
- البناء: bash scripts/build.sh ثم node scripts/validate-artifact.mjs. لا توجد مفاتيح خدمة داخل المصدر.

## استعادة النتائج بعد الفلاتر

عند عدم وجود تطابق في الدفعة المحمّلة، يعرض رادار الدفعة للاستكشاف مع تنبيه صريح بأنها غير مؤكدة الملاءمة وزر لمسح شروط العرض. لا يغيّر ذلك تقييم المشاريع إلى «مطابق». إجمالي نتائج GitHub منفصل عن عدد العناصر المحمّلة محليًا. إلغاء شروط العرض يحتفظ بإعداد الجهاز والخبرة.

## تصدّر موثّق

قسم مستقل يفرق بين متصدري الأرشيف، وترتيب صفحة GitHub Trending عند جلبها، وعينة نشاط الكود الحديث. يضم الأرشيف 558 مشروعًا تصدّروا قائمة كل اللغات، و7951 سجل مشروع/نطاق عبر 44393 لقطة أولى مؤرخة من 2021-12-31 إلى 2026-10-19. كل تاريخ مرتبط بملف أرشيف مثبت إلى commit؛ النطاق محفوظ ولا تُعامل صورة شارة بوصفها دليلًا. المصدر أرشيف مستقل وليس تصديقًا رسميًا أو سجلًا شاملًا لكل تاريخ GitHub.

الأرشيف التاريخي نسخة ثابتة؛ لتجديده راجع جامع المصدر ثم شغّل `python scripts/import-winners.py /path/to/github-trending-archive`. المصدر وترخيص MIT في winners.json وLICENSE-Trending-Archive.txt. الرائج يجلب صفحة GitHub الرسمية عبر مسار خادم ثابت /api/trending، بذاكرة مؤقتة لخمس دقائق ووقت جلب واضح. تعذر الجلب لا يعرض ترتيبًا قديمًا باعتباره الحالي. نشاط الكود يستخدم بحث GitHub عن مشاريع بأكثر من ألف نجمة دُفع إليها كود خلال سبعة أيام. تتجدد القائمتان كل خمس دقائق أثناء ظهور الصفحة؛ لا ندعي تحديثًا لحظيًا.
